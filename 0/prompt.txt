# Commit Skill

This skill enforces Gitmoji-style commit messages. It ensures that commit messages are brief, concise, and follow the Gitmoji convention. It only commits changes and does not push them. If no commit message is provided, the skill will infer one using `git status` and `git diff`.

## Important
- **Commit but do NOT push.** Push and pull operations will happen manually.

## Usage
When the user requests to commit changes, this skill will guide them to provide a Gitmoji-style commit message. The message should be brief and concise, following the Gitmoji convention. The skill will only commit the changes and will not push them. If it is unclear which files should be included, the skill will ask the user to specify. If no commit message is provided, the skill will infer one using `git status` and `git diff`.

## Example
- User input: `add new feature`
- Expected output: `:sparkles: add new feature`

## Dependencies
- Git
- Gitmoji knowledge (assumed to be known by the LLM)
